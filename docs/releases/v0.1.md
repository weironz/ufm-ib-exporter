# UFM IB Exporter v0.1

Rust exporter for existing NVIDIA UFM REST and native telemetry data. Deploy on the UFM host so large raw responses stay on loopback.

- Independently configurable REST, 9001 counters and 9002 CableInfo sources.
- Bounded streaming filtering, background caches, controlled concurrency and original observation-time freshness checks.
- Linux amd64 / arm64 static binaries, deployment configuration, systemd unit, Docker Compose, dashboards and example rules in each archive.
- Multi-platform Docker image: `willdockerhub/ufm-ib-exporter:v0.1` (also `v0.1.0` and `latest`).

The release tag `v0.1` corresponds to binary version `0.1.0`. Check `SHA256SUMS` before extracting. `docker-image.txt` records the published multi-platform image digest. See `deploy/README.md` in the archive for installation, TLS, configuration, validation and rollback.

This repository is private: use an authenticated GitHub CLI identity to download assets, for example `gh release download v0.1 --repo weironz/ufm-ib-exporter --pattern '*linux-amd64.tar.gz' --pattern SHA256SUMS`. Exporter services do not need GitHub credentials.

Deployment does not modify UFM/SM listeners or log into tenant servers. The exporter reduces its own parsing and memory overhead; UFM response generation still consumes resources and must be validated on site.
