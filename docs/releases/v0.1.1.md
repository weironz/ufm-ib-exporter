# UFM IB Exporter v0.1.1

Fix REST collection when UFM reports different physical ports with the same node/card description. Distinct peer or cage labels now keep these ports separate, matching the complete exported metric identity. Truly duplicate output series still fail the collection instead of being merged or counted twice.

Metric names, labels, telemetry collection and freshness behavior are unchanged. Linux amd64 / arm64 static binaries, configuration and both deployment methods are included in the archives. Verify `SHA256SUMS`; `docker-image.txt` contains the multi-platform Docker digest.

Docker image: `willdockerhub/ufm-ib-exporter:v0.1.1` (also `latest`). Installation and upgrades: `deploy/README.md`. The repository is public; release assets can be downloaded directly over HTTPS.
